## 6. 사용한 AI와 제작 과정

- **사용한 AI 도구**: 클로드, gpt
- **처음에 AI에게 한 요청(프롬프트)**:
  > 움직일 수 있는 캐릭터와 fps 게임에 맞는 배경을 3d로 만들어줘. 캐릭터의 시점은 1인칭이여야 되고 w, a, s, d로 전좌후우로 움직일 수 있어야 돼
- **AI가 만든 결과에서 내가 고치거나 추가한 부분**:

  -랭킹시스템, 여러가지 무기 추가 등 여러가지를 추가했습니다.
- **어려웠던 점과 해결한 방법**:
